# Security Policy

## Supported versions

Security fixes go into the latest release on the `master` branch. Please upgrade to the newest version before reporting.

## Reporting a vulnerability

Report vulnerabilities privately. Do not open a public issue.

- Preferred: use [GitHub private vulnerability reporting](https://github.com/TrueArrowSoftware/TASLibPHP/security/advisories/new) ("Security" tab, "Report a vulnerability").
- Or email **truearrowsoftware@outlook.com** with the subject "TASLibPHP security".

Please include the affected version, the PHP version, and steps or a proof of concept to reproduce.

## What to expect

- We acknowledge your report within **14 days**.
- We confirm the issue and agree a fix timeline with you.
- We publish the fix as a new release and describe it under the **Security** heading in [CHANGELOG.md](CHANGELOG.md), crediting you unless you prefer not to be named.

Reports and responses are kept private until a fix is released. After that, the advisory is published on the GitHub Security tab.
